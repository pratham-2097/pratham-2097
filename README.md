## What I'm building

| Project | What it does | Stack |
|:--|:--|:--|
| [**OmniRoute**](https://github.com/pratham-2097/OmniRoute) | LLM gateway: one API across model providers, with routing, failover, usage metering, and credit billing. Swap models without changing app code. | TypeScript · Bun |
| **ShadowHawk** | Drives headless Chromium to find undocumented APIs and exposed surfaces, triages findings with a local LLM, and exports SARIF. | Playwright · CDP · FastAPI |
| **DOORMAN** *(in progress)* | An agent that clicks through a web app on its own to map its real API surface and probe for prompt injection. | Agents · Playwright |
| [**canvas-mcp**](https://github.com/pratham-2097/canvas-mcp) | MCP server for UC Canvas: finds missing work and searches every course file from Claude. | MCP |
| [**Enma**](https://github.com/pratham-2097/Enma) | Agent payments, built at the x402 "Build Agent Payments" hackathon. | x402 |
| [**Opal**](https://github.com/pratham-2097/Opal) | Reusable auth and entitlements layer for SaaS apps. | Next.js · Convex |

**How these fit together:** discover what an agent can touch (DOORMAN, ShadowHawk) → route it to any model (OmniRoute) → give it tools (canvas-mcp) → control what it can do and pay for (Opal, Enma).
